
# YouTube Transcript Analyzer & Script Writer

 Một ứng dụng mạnh mẽ sử dụng trí tuệ nhân tạo (Gemini API) để phân tích bản ghi video YouTube, trích xuất chủ đề, dịch thuật, viết kịch bản motivational và tạo hình ảnh AI tự động.

 ## Phiên Bản Hiện Tại
 `PH.v.005.04.01.2026`

 ## Tính Năng Chính
 - **Màn hình Setup thông minh**: Tự động nhận diện cấu hình AI và yêu cầu thiết lập YouTube API khi khởi động hoặc khi đổi IP.
 - **Phân tích đa nguồn**: Trích xuất chủ đề chính và các điểm cốt lõi từ transcript hoặc URL.
 - **Biên tập chuyên nghiệp**: Tự động viết kịch bản kể chuyện motivational dựa trên nội dung phân tích.
 - **Tạo ảnh AI hàng loạt**: Tạo hàng loạt hình ảnh minh họa cho câu chuyện theo nhiều phong cách nghệ thuật.
 - **Bảo mật tối ưu**: Lưu trữ khóa API cục bộ và tự động yêu cầu xác thực lại nếu phát hiện thay đổi địa chỉ IP máy.
